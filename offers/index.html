Getting these out of the browser

  1. For Instagram or WhatsApp Status. Open a poster, right-click it → Inspect, right-click the <div class="poster"> node → Capture node screenshot. You get an exact 1080 × 1350 PNG.
  2. For printing. Open the poster and press Ctrl+P. The page is already set to A4 portrait with no margins — leave Headers and footers off, and turn Background graphics on, or the cream paper and the cocoa footer print white.
  3. Changing a price or a date. Every figure is plain text in the HTML — open the file in any editor and type over it. Colours and type live once in poster.css; change them there and all nine follow.
